Историческая совместимость — старые выполненные квитанции без ключей срабатывания продолжают поддерживать replay по preview id. Невыполненные старые preview и новый пакет без ключей получают 409 с требованием обновить preview или plans-service. До появления новой таблицы повтор через новый preview не может быть восстановлен из отсутствовавших ключей. Выпуск требует миграций plans и workouts, затем обновления сервисов и workers. Внешний LLM, Firebase, физическое устройство и production в этот прогон не входят.

Последний полный прогон после проверки совместимости завершился с exit 0. test_macro_and_editor_share_workout_lock также проверяет 409 для пакета старого producer и невыполненного старого preview, а затем replay старой выполненной квитанции. Ruff и git diff --check для изменённых областей прошли.
